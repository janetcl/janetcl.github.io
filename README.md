# janetlee.me

My personal site, served by GitHub Pages from `master` (custom domain in `CNAME`).

| Path | What | Where it lives |
| --- | --- | --- |
| `/` | the current site | `index.html`, `style.css`, `site.js`, `img/` |
| `/files/` | resume PDF, thesis, favicon | `files/` |
| `/resume/` | source of the resume PDF | `resume/resume.html` |
| `/archive/` | the 2020 site, kept as-is | `archive/` |
| `/draft/` | old preview link, redirects to `/` | `draft/` |
| `/dance-studio/` | Dance Studio app | its own repo, [janetcl/dance-studio](https://github.com/janetcl/dance-studio) |
| `/alabaster-site/` | alabaster.org rebuild preview | its own repo, [janetcl/alabaster-site](https://github.com/janetcl/alabaster-site) |

The last two show up under janetlee.me because they're GitHub Pages project sites on the same account. Keep this repo named `janetcl.github.io` with the custom domain, or those paths stop working.
